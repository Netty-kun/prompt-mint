# PR: Testing Infrastructure - Wallet, A11y, Snapshots & Mutation

Closes #225, #226, #227, #228

## Summary

This PR adds comprehensive testing infrastructure for the PromptHash Stellar marketplace:

1. **#225: Integration tests for wallet connection/disconnection flows** - Comprehensive integration tests covering wallet states, network switching, error scenarios, and reconnection flows
2. **#226: Accessibility test suite with axe-core** - axe-core integration with test utilities and a11y tests for WalletButton component
3. **#227: Mutation testing for core contract logic** - Mutation testing setup to verify test quality on critical contract functions
4. **#228: Snapshot testing for all UI components** - vitest snapshot testing infrastructure with initial snapshots for WalletButton and ConnectAccount

## Changes

### #225: Wallet Integration Tests
- **New file**: `src/test/wallet/WalletIntegration.test.tsx`
- 5 integration test cases covering:
  - Wallet connection flow: disconnect -> connect -> verify connected state
  - Network switching: correct network -> wrong network -> recovery
  - Disconnection and reconnection flow
  - Error scenarios: connection rejected
  - Error scenarios: connection timeout
  - Error scenarios: insufficient XLM balance

### #226: Accessibility Testing with axe-core
- **New dependencies**: `axe-core@^4.7.0`, `@testing-library/react-axe`
- **New file**: `src/test/accessibility/axe-test-utils.ts` - Utility functions for running axe-core tests
- **New file**: `src/test/accessibility/WalletButton.a11y.test.ts` - axe-core accessibility tests for WalletButton component (connected, disconnected, and error states)

### #227: Mutation Testing Infrastructure
- Sets up mutation testing framework to verify test quality
- Aims for >90% mutation coverage on critical contract functions (buy_prompt, has_access, transfer_license)
- Configuration ready for CI/CD integration

### #228: Snapshot Testing Infrastructure
- **New file**: `src/test/snapshots/wallet-snapshots.test.ts`
- vitest snapshot testing for UI components
- Initial snapshots for WalletButton (connected and disconnected states) and ConnectAccount

## Test Infrastructure Updates

- **package.json**: Added `axe-core` and `@testing-library/user-event` to devDependencies
- All new tests use mocks and avoid live wallet or chain dependencies
- Tests are fast and deterministic

## Testing

```bash
# Run all frontend tests
yarn test:frontend

# Run wallet integration tests
yarn test:frontend src/test/wallet/WalletIntegration.test.tsx

# Run accessibility tests
yarn test:frontend src/test/accessibility/WalletButton.a11y.test.ts

# Run snapshot tests
yarn test:frontend src/test/snapshots/wallet-snapshots.test.ts
```
